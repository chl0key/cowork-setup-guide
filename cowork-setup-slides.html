Part 0

The Discovery Process

Before you build anything, have real conversations with Claude. 4 conversations. ~45 minutes total. No files created yet.

6
Edit

The 4 Discovery Conversations

  1. Who You Are (15–20 min) — Work, goals, daily routine, tools, what's broken
  2. How You Work (10–15 min) — Preferences, productivity patterns, time sinks
  3. The Personal Stuff (10–15 min) — People, hobbies, food, writing pet peeves
  4. Your AI Relationship (5–10 min) — Experience, comfort level, dream scenario
7
Edit

Discovery Pro Tips

  • Ask Claude to go ONE question at a time — don't dump all questions at once
  • Paste real writing samples. One email teaches more than a paragraph of adjectives.
  • Tell Claude to ask follow-up questions beyond the script
  • Save everything to discovery-notes.md
Pro move: Read your discovery notes aloud. You'll catch the real patterns.

Global Instructions

What Global Instructions Include

  • Who I Am — 1–2 sentences. The essentials.
  • How to Work With Me — Behavioral rules that matter to you
  • Output Style — Tone, format, length preferences
  • Standing Rules — Non-negotiable every-session rules
  • Quality Standard — Re-read output, verify facts
  • How to Work Smarter — Parallel research, extended thinking, etc.

Part 2

CLAUDE.md

The single most important file in your system. Lives at the root of your workspace. Claude reads it automatically.

11
Edit

CLAUDE.md — The 3 Rules

1
Keep It Under ~150 Lines
It's the index, not the encyclopedia. Link to memory files for detail.
2
Link, Don't Duplicate
CLAUDE.md points to deeper files. Claude reads only what's relevant.
3
Update Regularly
Every weekly review should include a refresh. Keep it current.

Memory Files

The 5 Core Memory Files

  1. writing-voice.md — How you actually sound (THE most important one)
  2. people.md — Key people, enough context to never ask "who is [name]?"
  3. life-areas.md — Routine, fitness, hobbies, goals, personality patterns
  4. career-profile.md — Education, role, target, job search status
  5. glossary.md — Decoder ring for your life's acronyms and jargon

writing-voice.md — The Magic File

Real writing samples beat descriptions. Every time.

What goes in:

  • Voice characteristics (bold? funny? formal? casual?)
  • Professional style
  • Casual style
  • Sign-off habits
  • Punctuation quirks
  • Banned words
  • 3–5 real writing samples with annotations
This file is your secret weapon. It teaches Claude how to sound like you better than any rubric could.

Automation Ground Rules

  • Laptop must be awake + Claude Desktop open
  • Be specific in the prompt (don't say "check my email" — say exactly what to scan, prioritize, format, save)
  • Include file paths for where to save output
  • Reference skills for format and tone
  • Check outputs for the first few days — they need tuning
Automations work best when they're specific, not vague.

The Corrections Loop

  1. Fix the mistake immediately
  2. Log it in CLAUDE.md under Corrections & Learnings
  3. Check if it reveals new info → update memory file
  4. Check if it reveals a skill gap → propose SKILL.md update
This is the single most important maintenance mechanism. Your system gets smarter with every mistake.

10 Lessons That Actually Matter

  1. Real writing samples beat descriptions. Always.
  2. Negative instructions matter as much as positive ones. "Don't do this" is as important as "do this."
  3. The correction loop is your secret weapon. Embrace it.
  4. Discovery before building. Always. No exceptions.
  5. Skills need boundaries. "Do NOT use for" matters.
39
Edit

10 Lessons (continued)

  1. Less is more in CLAUDE.md. ~150 lines, link to memory files.
  2. Start with one pain point, not everything at once. Build progressively.
  3. Automations need babysitting at first. Check outputs, tune, iterate.
  4. Specific beats comprehensive. "Draft an email to Nancy about X" > "draft an email."
  5. If maintaining it feels like work, something is wrong. Redesign.
