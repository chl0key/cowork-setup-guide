Before you start · 5 minutes

Make Claude a home.

Claude gets one folder on your computer. It can read and write in there and nowhere else, so everything else on your computer stays untouched.

  1. Open Finder and click iCloud Drive in the sidebar
  2. Right-click an empty spot › New Folder
  3. Name it Cowork Workspace. Exactly that is fine. Short, no dates, easy to spot
  4. Right-click the folder › Keep Downloaded. iCloud sometimes swaps files for placeholders to save space, and Claude can't read those
  5. Drag it to the Finder sidebar so it's one click away

  4. Right-click the folder › Always keep on this device, so Claude can read every file
  5. Right-click › Pin to Quick access

Step 1 of 5 · 4 minutes

Connect your folder, then run the built-in setup.

Connect your folder

  1. Open the Claude desktop app. Claude does the work in the cloud. Your folder stays on your computer, so keep the desktop app open while Claude works in there
  2. Start a new conversation
  3. Under the message box, click Project or folder. You can also click + › Add folder
  4. Pick your Cowork Workspace folder and click Open
  5. The first time, Claude asks for permission to use the folder. Allow it. Every folder you allow is listed under Settings › Trusted folders
  6. Send your first message. A Cowork Workspace folder card shows above it. That's how you know it's connected
  7. Test it: ask "What's in this folder?" Claude should list your files

Find my level-ups


I want to find the best places in my week for you to help me. Interview me to find them.

Rules:
- Ask one question at a time. Keep questions short and plain.
- If my calendar, email, or folder is connected, look at last week first and tell me what repeats before you ask anything.
- Push for specifics: how often, how long it takes, which apps or files I use.
- After every five questions, recap what you've heard in three lines.
- Stop after about 12 questions, or sooner if you have enough.

Then give me a short table of my top 5 candidates. Score each one yes or no on:
1. Again: I do it weekly or monthly, the same way
2. Boring middle: the hard part is gathering, copying, reformatting, or summarizing
3. Easy to check: I can tell in two minutes if you got it right

Flag anything that sends messages to other people, touches money, or is something I'm trying to learn. Those stay hands-on or draft-only.

For each one, say which mode fits: "Do it for me" (scheduled task), "Do it with me" (a skill I start), or "Keep an eye on it" (a brief or dashboard). Estimate minutes saved per week.

End by recommending the ONE to set up first and the exact first step. Save the table to my folder as automation-ideas.md.

  
Can't think of anything?
Keep an "ugh, this again" list for five workdays. One line each time. On Friday, paste it into Claude with the prompt above.

Organize your folder
+
15 minNeeds: your folderLow risk
A simple layout and file names Claude can find things with
      

        
Why: Claude finds things by opening folders and reading file names. Clear names and small folders mean it finds the right file on the first try, and uses less of your limit doing it.

        

          
inbox/Dump zone. Claude sorts it for you

          
projects/Things with a finish line, one folder each

          
areas/Ongoing parts of life: work, health, money, home, people

          
reference/Things you look up: recipes, how-tos, templates

          
examples/Your best work: emails you're proud of, a great deck, a doc that landed. Claude copies what good looks like

          
archive/Done. Out of the way, never deleted

        

        
File names that work

        

          
2026-09-24_gala-vendor-list.mdDate first so things sort in order. Then a few words a stranger would understand

          
One idea per fileTen small files beat one giant one. Claude reads less to find more

          
Date everythingA note with no date looks current forever. Dates let Claude tell this week's decision from March's

        

        
Prompt


Set up my folder so you can find things fast.
1. Create these folders: inbox, projects, areas, reference, archive. Add a one-line README in each saying what goes there.
2. From now on, name every new file like 2026-09-24_short-topic.md. One idea per file.
3. Add a short "where things live" map to about-me.md.
4. If I have notes in Apple Notes, Notion, or Google Docs, tell me how to export them, then sort the export into these folders. Leave live shared pages where they are.
Show me the plan before you create anything.

        
Give each busy folder its own CLAUDE.md

        
Your main CLAUDE.md covers the whole workspace. A big project or area can get a small CLAUDE.md of its own, so Claude gets up to speed on it without reading every file inside. Add a decision-log.md next to it, with a date on every entry.

        
Folder CLAUDE.md


Create a CLAUDE.md for my [project name] folder. It should help a new chat understand this project without reading every file in it.
Include:
- what this project is, in 3 to 4 lines
- current status and open decisions, each with a date and the file it came from
- a map: which file to open for which kind of question
Mark anything not yet approved as unapproved. Leave a TODO where facts are missing. Don't guess.
From now on, when we make a decision here, add it to decision-log.md with today's date and update this CLAUDE.md.

        
Adapted from JJ Englert's file system playbook at Tenex. Do this for any folder you open more than once a month.

        
Check it worked
Ask: "Find everything I have about [a topic]." If it misses files you know exist, that folder is too big or the names are too vague. Split it up. More instructions won't fix it.

Stack your chats in a Project
+
10 minNeeds: desktop appLow risk
Chats that build on each other, so you stop re-explaining
      

        
What it is: a Claude Project is a home for one part of your life, like a big work project or a wedding. It points at a folder, has its own instructions, and remembers every chat you have inside it.

        
Why it matters: a Project keeps related files, a goal, and its chats in one place, so you stop re-explaining.

        
When to make one: any area you chat about every week. Start with your busiest one.

        
    
          
  1. In the left sidebar, click Projects › New project
    2. 
          
  2. Give it a short name you'll recognize
    3. 
          
  3. Add a one-line goal, like "Plan the March gala: venue, vendors and run of show"
    4. 
          
  4. Under Context, click Add and pick a folder. Your whole Cowork Workspace folder works, or one busy folder inside it, like projects/spring-gala
    5. 
          
  5. Click Create project
    6. 
          
  6. From now on, start every chat about that topic inside the project
    7. 
          
  7. Rename chats as you go, like "Vendor shortlist," so you can find them later
    8. 
        

        
The Key
Projects remember conversations. Files remember decisions. When a chat settles something, ask Claude to add it to the folder's decision-log.md, so it lasts beyond the project.

        
Check it worked
Start a second chat in the project and ask about something you only mentioned in the first one. It should know without you repeating it.

Every Monday at 7am, read my calendar and email for the week ahead. Read only.
Give me:

When something's off

  
Quick fixes.

  

    
My screen doesn't match this guide
Anthropic is rolling out the new Claude slowly, so two people on the same plan can see different menus this week. If your message box shows Chat and Cowork options, you're on the old layout. Tell me what you see and I'll update the guide.

    
Claude can't find my files
Every new chat starts without a folder. Click Project or folder and pick Cowork Workspace. Then ask Claude to list the files it can see.

    
Claude answers from memory and skips my CLAUDE.md
Check your global instructions in Settings › Account. They need the line "When working in a folder, read its CLAUDE.md first." Without it, Claude may answer from memory and never open the file.

    
Claude doesn't remember me
Check that Settings › Memory is on. Then run the Step 5 check. Old tasks that ran only on your computer before October 6, 2026 kept their memory to themselves.

    
It ignored one of my rules
Put it in about-me.md or your Instructions, and say why. Rules with a reason stick better. If it keeps happening, your file might be too long. Aim for under 200 lines.

    
My scheduled task didn't run
Check Scheduled for the run's status. Cloud tasks can run with your laptop closed, but local files need the desktop app open and your computer awake.

    
A connected app stopped working
Logins expire. Customize › Connectors › Reconnect, and sign in again.

    
I hit my usage limit super fast
Long tasks that search, run code, or make files use more than a quick question. Auto mode and higher effort use more too. Start a new conversation for each new topic, and try Sonnet for simple questions.

    
Claude wants to delete files
It always asks first. Say no if you're not sure. That's what the backup is for.
