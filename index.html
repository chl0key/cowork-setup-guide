Pro Tip
Already been using ChatGPT or Gemini? Start here.
Import your conversation history and skip half the setup work.

All those questions you asked, the emails you drafted, the things you researched, the way you phrased your prompts. That's months of data about how you think, what you care about, and how you actually talk. Instead of starting the discovery process from scratch, you can import that into Claude's memory and give it a head start on knowing you.

This step is optional. If you're brand new to AI, skip ahead to the Discovery Process below. But if you've got history with another tool, the 5 minutes it takes to import will save you time on everything that follows.

Step 1: Export Your Data

Coming from ChatGPT

ChatGPT has a built-in data export. Click your profile icon in the bottom left, go to Settings > Data controls, and click "Export" next to "Export data."

Screenshot 1
ChatGPT Settings > Data controls showing the "Export data" option at the bottom

You'll get a confirmation dialog. Click "Confirm export" and ChatGPT will email you a download link with a ZIP file containing your full conversation history.

Screenshot 2
The "Request data export" confirmation dialog with the "Confirm export" button

Coming from Gemini, Grok, or another AI

Most other AI tools don't have a built-in export yet. Instead, open a conversation with your AI and send it this message:

"I'm moving to another service and need to export my data. List every memory you have stored about me, as well as any context you've learned about me from past conversations. Output everything in a single code block so I can easily copy it."

It'll spit out a block of text with everything it knows about you: your preferences, writing style, projects, people you mention, corrections you've made. Copy that entire block.

Step 2: Import It Into Claude

In Claude Desktop, go to Settings > Capabilities > Memory and click "Import memory from other AI providers."

Screenshot 3
Claude Desktop Settings > Capabilities > Memory showing "Import memory from other AI providers"

You'll see a text box. If you exported from ChatGPT, Claude's import tool will walk you through it. If you used the prompt method for Gemini or Grok, paste the text block you copied. Either way, click "Add to memory" and Claude will process everything and store it as individual memory entries. You can click "Manage edits" to review what it saved.

Then Start Discovery

Once the import is done, head straight to the Discovery prompts in the next section. The first prompt is built to handle both paths: if you imported data, Claude will start by showing you everything it thinks it knows and ask you to confirm, correct, or update it before moving on. If you didn't import anything, it skips that step and interviews you from scratch. Either way, you end up in the same place.

Good to know

The memory import is experimental and Claude may not capture everything perfectly. That's fine. The discovery process will fill in any gaps. Think of the import as a head start, not a replacement for discovery.

Also, before you export, skim through what your AI spits out. If it includes anything sensitive (passwords, financial details, work stuff you shouldn't share), edit those out before pasting into Claude.

Part 0

The Discovery Process

Before you fill in a single template, you need to have the right conversations with Claude. The quality of your system depends entirely on the quality of information you put into it.

Here's what to do: Open Claude Desktop, click Cowork at the top, and start a new session. Then copy the first prompt below and paste it into the text box. Claude will start asking you questions — just answer them naturally. When you finish one prompt, paste the next one into the same chat and keep going.

Keep all 4 prompts in one session

Do all 4 Discovery prompts in the same CoWork chat. Don't start a new session between them — Claude needs the context from each conversation to build on the next. Paste one prompt, answer the questions, then paste the next when you're ready. You can take breaks, just come back to the same session.

Who You Are (15-20 min)

Paste this into CoWork
I'm setting up my CoWork second brain from scratch. I want you to interview me so you can build a system that actually knows me. Before you start asking questions, check if you have any imported memory about me from another AI provider (ChatGPT, Gemini, Grok, etc.). If you do, don't assume any of it is correct. Instead: 1. Show me everything you think you know about me, organized by topic — who I am, what I do for work, my goals, my daily routine, how I communicate, people in my life, my preferences, my pet peeves, tools I use, and anything else you picked up. 2. Be specific. Don't just say "you prefer casual communication." Show me the actual details, examples, or patterns you're basing that on so I can tell you if they're right. 3. Then ask me: "What's still accurate? What's changed? What did I get wrong?" 4. Wait for my answers. Use my corrections to update your understanding, then move to the questions below — but only ask the ones you don't already have solid, confirmed answers to. If you don't have any imported memory, skip the above and go straight to the questions. Start with who I am. Ask me these questions ONE AT A TIME (wait for my answer before moving to the next). Go conversational, not robotic: 1. What do I do for work? Not just my title, but my actual day-to-day. 2. What am I working toward right now? Career goals, personal goals, active projects. 3. Walk me through a typical weekday. Then a typical weekend. 4. What tools do I already use? (Note-taking, calendars, email, project management) 5. What's broken in my current system? What falls through the cracks? 6. What have I tried before that didn't work? (And why did it fail?) After I answer all 6 (or after we've validated the imported data and filled any gaps), summarize what you learned and ask if I'd add or correct anything. Then save the notes to a file called "discovery-notes.md" in my workspace so we can reference them when building the system. Don't limit yourself to just these questions — if something I say sparks a follow-up or you think of other questions that would help you understand me better, ask those too.
Claude will ask each question one at a time and wait for your answer. If you imported memory, it'll validate that first.

Questions covered in the prompt above: your work, goals, daily routine, current tools, what's broken, and what you've tried before. If you imported memory, Claude validates all of that before asking questions.
